# DineDesk – Canteen Food Ordering System

## About the Project
DineDesk is an android Java-based canteen food ordering and management application developed using Android Studio. It aims to simplify food ordering and order management through customer and admin interfaces.

## Features
- Customer and admin interfaces
- Food ordering and order management
- Order token generation
- GST and bill calculation
- Receipt generation
- Order status management

## Technologies Used
- Java
- XML
- Android Studio
- Gradle

## Data Storage
The current implementation uses in-memory storage for order records. Data is not permanently stored in a database.

## Future Enhancements
- Database integration for persistent storage
- Improved authentication and security
- Online payment integration
- Order notifications
